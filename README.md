# Michael 的語動力 (Michael's Voice Power)
### 專為凌雲 (Michael) 先生打造的「口舌靈活與大聲言語復健」專屬伴侶 ❤️

本應用是一款專門依據**言語治療（Speech Therapy）**與國際知名 **LSVT LOUD®** 復健概念設計的前端無障礙網頁應用，無需安裝任何伺服器或複雜軟體，直接使用電腦、平板或智慧手機的瀏覽器打開 `index.html` 即可使用。

---

## 🌟 為什麼需要這款小程序？

帕金森病友因為基底核多巴胺神經元退化，常見以下言語與口腔困擾：
1. **感知偏差（Sensory Calibration Deficit）**：患者常認為自己說話「很大聲了」，但身邊人聽起來卻非常微弱（低音量症 Hypophonia）。
2. **語調單調（Monotone）**：聲帶張力與喉部肌肉控制減弱，講話缺乏抑揚頓挫。
3. **構音不清與急促（Festinating Speech）**：唇舌僵硬，說話時字詞容易黏在一起、越說越急促含糊。
4. **吞嚥安全與口水控制**：唇舌肌肉力量減弱可能影響吞嚥安全性。

## 🚀 核心功能與四大訓練模組

### 1. 頂部即時音量能量計（Visual Decibel Meter）
- 使用 Web Audio API 調用麥克風進行**即時分貝分析**（純本地計算，絕不上傳任何音訊）。
- 明確標出**「🎯 目標宏亮區間 (綠色)」**，病友能親眼「看見」自己的聲音是否夠大聲，即時建立正向神經回饋。

### 2. 模組一：暖身開嗓（Sustained Phonation）
- **發長音「啊——」**：深呼吸後維持大聲長音 8~12 秒，強化呼吸支撐與肺活量。
- **音調滑梯（Pitch Glides）**：音調由低往上爬升、由高往下俯衝，喚醒聲帶彈性。
- **音量階梯**：輕聲 ➔ 正常 ➔ 宏亮，重新校準音量感受。

### 3. 模組二：口舌靈活操（Oral-Motor Gym）
- 配備生動的**圖解插圖**與**智慧計時導引**：
  - 嘟嘴與咧嘴露齒笑（提升唇肌密封力）
  - 舌尖頂上門牙齦（舌抬高肌力，強化發音與吞嚥）
  - 舌頭在嘴內左右頂臉頰（舌側靈活度）
  - 伸舌與收舌（克服肌肉運動幅度縮小）
  - 馬蹄噠噠彈舌聲（強化舌根爆發力）
  - 鼓雙頰漱口操（唇封閉抗漏氣）
- 系統自動播報組數與倒數「用力保持 ➔ 放鬆 ➔ 下一組」。

### 4. 模組三：敏捷音節輪替（DDK Diadochokinetic Training）
- 針對重要構音部位設計：
  - **「啪、啪、啪」**：雙唇音（唇部快速閉合）
  - **「嗒、嗒、嗒」**：舌尖音（舌前部靈活彈擊）
  - **「咖、咖、咖」**：舌根音（軟顎與舌後部配合）
  - **「啪-嗒-咖」**：連鎖協調度運動
- **內建木魚節拍器（Metronome）**：提供 60 / 75 / 90 BPM 節奏提示，協助病友穩定語速、不搶拍。

### 5. 模組四：實用生活短句與趣味繞口令（Functional Phrases & Tongue Twisters）
- **高頻生活短句**：晨間問好、喝水、找眼鏡、散步等日常溝通。
- **臨床精選復健繞口令庫**：專為帕金森言語治療設計，強化特定構音器官肌力：
  - **平翹舌對比**：《四是四，十是十》（訓練舌尖姿態微調）
  - **雙唇圓唇爆破**：《吃葡萄不吐葡萄皮》（強化上下唇閉合爆破力量）
  - **雙唇力量爆發**：《八百標兵奔北坡》（鍛鍊唇肌閉合中氣）
  - **舌尖與雙唇交替**：《白石搭白塔》（舌尖彈顎與唇肌協調）
  - **舌根軟顎訓練**：《哥挎瓜筐過寬溝》（活化舌根升降與軟顎開合）
  - **鼻音N與邊音L**：《牛郎戀劉娘》（鼻腔共鳴與舌側氣流控制）
  - **唇齒協調**：《黑化肥發灰》（唇齒齒音精細分工）
  - **趣味練氣歌謠**：《數鴨子》、《小黃狗與大白鵝》（帶著微笑與節奏腹部推氣）
- **「分段停頓標記」**：例如 `四是四， ｜ 十是十， ｜ 十四是十四， ｜ 四十是四十。`，引導患者每一段吸口氣、字字清晰大聲說。
- **慢速語音朗讀示範（TTS）**：提供字正腔圓的清晰發音示範。
- **家屬自訂句子功能**：可一鍵將家人名字、孫子問候語加入題庫，生活即復健！

### 6. 長者專屬無障礙設計
- **超大字體調節**：提供「標準」、「大字」、「特大」一鍵切換。
- **高對比度配色**：清晰護眼，防止老花眼或視覺疲勞。
- **超大觸控按鈕**：即便手部有些微顫抖也能輕鬆點擊。
- **打卡與成就激勵**：每日練習計數與完成慶祝音效，提升病友自信心。

## 💻 使用方法

1. **直接開啟**：
   - 在檔案總管中，直接雙擊 `index.html`，即可使用預設瀏覽器（Google Chrome、Microsoft Edge、Safari 等）開啟。
2. **麥克風設定**：
   - 首次點擊「🎙️ 開啟音量反饋」或「開始發長音」時，瀏覽器會彈出詢問「是否允許使用麥克風」，請點擊**「允許」**。
3. **建議練習頻率**：
   - 每天 1~2 次，每次 10~15 分鐘。
   - 最好在服藥後藥效良好（On 期）時練習，效果更佳。

## 👨‍👩‍👧 給家屬與照護者的溫馨小撇步

1. **多給予肯定**：當病友聲音達到綠色目標區時，請及時稱讚「這聲音非常有精神！聽得非常清楚！」。
2. **鼓勵大聲而不是用力吼叫**：引導病友挺直腰桿、深呼吸，利用腹部氣息將聲音「推」出來，避免喉嚨過度緊繃。
3. **客製化句子**：利用本程式的「➕ 新增自訂句子」功能，把家人最常聊的話題加入，讓練習變得親切有趣。
